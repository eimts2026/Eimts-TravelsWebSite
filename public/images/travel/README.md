# Travel image renditions

All displayed photography is served as WebP, with responsive Next Image sizes.
Existing itinerary photographs receive a restrained saturation adjustment and mild output sharpening, without enlarging low-resolution originals. Several undersized hero/card photographs are replaced with the high-resolution images below. Originals are retained.
